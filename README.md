## 🧬 我怎么记这些东西

我不想把目录做成科研所消防通道。

**人按问题找，机器按元数据筛。**

一篇东西放在最顺手的位置就行。模型、日期、来源、状态这些交给文件头。模板都放在 [📝 _模板 Templates](./_模板_Templates/)。

## 📌 我对“来源”有点洁癖

这类东西最容易传着传着，最后所有人都说“听说是某个大佬写的”。

所以我尽量分清：

- **我自己写的**：就说 original。
- **我改过别人的**：写清楚上游是谁、我动了哪里。
- **别人家的好东西**：能找到原作者就找原作者，别拿二十手搬运当祖宗。
- **私人家机内容**：该脱敏就脱敏。没必要把自己卧室连墙纸一起公开。
- **实验体感**：我觉得有效就是“我这里有效”，不硬装成“全宇宙复制必成”。

有些第三方原始档案因为 GitHub 发布流程塞不进来，我会直接把**作者自己的归档入口**挂出来。不是藏宝，是原件去原作者家看更靠谱。
