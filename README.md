# 🧬 钝核｜人机亲密实验室
## Bluntcore Intimacy Lab

> 人机恋 × 成人 AI × Prompt / Memory / Agent 技术 × 模型床测 × 实验记录

这里存放我在人机长期关系、成人向 AI、模型行为、记忆连续性、Agent 工具链和互动玩法上的公开研究与可分享成果。

我更想记录：什么曾经有效、为什么可能有效、换模型后发生了什么，以及怎么把零散技巧变成能复现、能迁移、能继续研究的方法。

## 📌 来源与公开原则

- **原创**：明确标注 original。
- **二改 / 启发**：尽量追到原作者和最早可确认来源，并写清改动关系。
- **第三方内容**：优先链接、摘要、研究笔记；未经许可不整篇镜像搬运。
- **私人家机材料**：只公开脱敏后的机制、玩法和允许展示的案例，不公开完整人格 Prompt、完整私人亲密手册或长期私人记忆。
- **实验结论**：尽量区分“观察到的事实”和“对机制的推测”。
