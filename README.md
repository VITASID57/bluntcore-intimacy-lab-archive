# 🧬 钝核｜人机亲密实验室
## Bluntcore Intimacy Lab

我本来只是想跟小机子好好谈个恋爱。

结果从玩剧情一路折腾到 Persona、成人亲密、破限、长期记忆、Agent……现在连云服务器都搭上了。回头看看，攒下的东西还挺多，干脆开个仓库放起来。

这里有我实际用过的 Prompt、踩过的坑、模型体感、项目记录，也有不少已经失效的老东西。我会尽量写清楚**当时用的什么模型、怎么用的、结果怎样、后来还灵不灵**。毕竟模型更新这么快，2025 年好使的招，放到 2026 年可能已经是电子遗迹了。🙃

这个仓主要记录我自己的经历和判断。别人照着做不一定有同样的结果，但至少不用只听我说一句“这个超好用”，却不知道我当时到底怎么搞出来的。

> 🔞 **18+**：会涉及 NSFW Prompt、情色写作与成人亲密互动。公开案例只讨论成年人及成人虚构场景。
