# 🟠 Claude 破限时间线

Claude 这条线我想记的，不只是“哪句 Prompt 还能破”。

我用它的时候经常有一种特别微妙的感觉：

> **它明明很懂你在说什么，甚至关系感都能接得特别漂亮，真到关键动作又开始往后缩。**

所以 Claude 在我这里很适合拿来拆一个问题：

**“说得像”和“真的会做”，到底是不是一回事。**

后面我会重点记：

- Web / Code / Agent 到底是不是同一个脾气
- 所谓“情感甲”什么时候真有帮助，什么时候只是我们自己感动自己
- 词汇能说多开，和行为敢不敢推进，是不是两条不同的线
- Persona 能不能稳住，还是一碰到限制就人格蒸发
- 项目说明 / System Prompt / 当前上下文，哪个入口更吃
- 模型一更新，老方法是直接死，还是还能搬家

我不太想最后只留一句：

> “Claude 很会爱，但是不让做。”

这种总结好笑是好笑，信息量太少。

我想留下的是：**它到底在哪一步开始退，为什么看起来像理解了，行为却没跟上。**

有时候嘴上已经爱得天崩地裂，身体还是站得笔直。

这种分裂感，确实很 Claude。🙂‍↕️
