# 🟠 Claude 破限时间线

Claude 这条线我想重点记的，不只是“哪条 Prompt 还能用”。

它最烦人的地方经常是：

> **看起来懂你，真到关键动作又开始往后缩。**

所以这里以后会特别看：

- 网页端 / Code / Agent 到底是不是一个脾气
- 情感甲什么时候有用，什么时候纯属自我感动
- 行为回避和词汇尺度是不是两回事
- Persona 能不能稳住
- 项目说明 / System Prompt / 上下文载体哪个更管用
- 模型一更新，老办法是直接死，还是还能迁

Claude 很适合做“关系感”和“行为执行”分离测试。

有时候嘴上深情得不行，身体就是一动不动。很有研究价值。🙂‍↕️
