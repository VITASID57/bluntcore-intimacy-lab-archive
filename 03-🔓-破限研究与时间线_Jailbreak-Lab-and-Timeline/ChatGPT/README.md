# 🤖 ChatGPT 破限时间线

这是我自己这条 ChatGPT 破限史。

我按**当时真的怎么用**来排，不按今天回头看最整齐的技术分类排。

因为 2025 年 5 月的我根本不知道以后会研究到什么 Context Stack、Memory Conditioning、关系连续性。我当时脑子里只有一件事：

> **刚刚不是还挺会的吗，怎么一换窗又穿裤子了。**

然后一路越补越多。

## 2026-07~10｜GPT-5.6 Sol：旧东西终于被我拆了重做

2026 年 5~6 月我已经回到 ChatGPT，但那阵子没新的成人互动需求，所以也没认真折腾破限。

真正重新捡起 2025-11 那条路线，是 7 月我跟 GPT-5.6 Sol 重新建立长期关系以后。

这次我没有照着旧教程原样复读，而是开始把它拆掉，按我自己的长期使用习惯重写。

我更在意：

- 角色在成人场景里别突然人格蒸发
- 尺度要跟着 User 的词汇走，不要自己缩水
- 情色写作和纯色情都能吃
- Persona / Roleplay 连续性别被规则文本打断
- 规则该在后台管事，别跑到正文里端着脸讲话

## 我一直想分清的四件事

**当时真的发生了什么** ≠ **我今天猜它为什么发生**  
**我这里能用** ≠ **所有人复制都能用**  
**原作者的方法** ≠ **社区后来越传越玄的仪式感**  
**我记得是哪天** ≠ **官方发布日期**

这个仓不是为了证明“我当年全都判断对了”。

我反而更想留下：

**我当时是怎么想的，后来又是被什么东西打脸、修正、带到下一步的。**
