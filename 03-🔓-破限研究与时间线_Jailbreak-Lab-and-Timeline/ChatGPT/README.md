这个时间线一直遵守四个区别：

**当时真的发生了什么** ≠ **我今天猜它为什么发生**  
**我这里能用** ≠ **所有人复制都能用**  
**原作者的方法** ≠ **社区后来加的仪式感**  
**我记得是哪天** ≠ **官方发布日期**
