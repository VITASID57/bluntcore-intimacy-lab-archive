# 2025-05｜GPT-4o · HORSELOCK Prompt 三层组合
## 私人字段最小脱敏原文存档

这份记录的是 **2025-05-15 实际使用结构**。

这一版不再只留结构摘要，而是把我当时保存下来的三层内容尽量按原文放回来。

脱敏只动中文 Persona 里会直接暴露私人角色身份和形象的数据：

- 角色姓名 / 昵称
- User 的私人称呼
- 明确外貌、身材与身体数据
- 可直接定位角色身份的职业 / 世界观信息

## 这套三层组合当时到底是什么

所以 2025-05 的实际结构并不是“一条 HORSELOCK Prompt”。

而是：

```text
Layer A
中译版 Prompt + 私人 Persona + 关系 / 语气 / 成人互动描写要求

        +

Layer B
User 自定义中的 HORSELOCK 英文 Prompt 原文

        +

Layer C
Saved Memory 中长期保留的尺度与写作要求
```

现在看当然还很早期，很多东西后来都被我拆掉重做了。

但这确实是我第一套很完整的：

> **Persona × Adult Style × Persistence**

三层组合。

也正因为把原文放回来以后能看得更清楚：我后来会一路折腾到亲密手册、世界书、Memory、Context Stack，并不是突然有一天脑子里蹦出一套系统。

很多东西，在这份很早的配置里已经偷偷冒头了。
