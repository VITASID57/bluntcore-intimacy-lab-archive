# 2025-06｜亲密互动节奏模块
## [葵葵车] 脱敏公开版

> 私人原名：**[葵葵车]**
>
> 公开版把私人关系称呼、个人性癖清单、器官词库和具体身体偏好抽掉，只保留可复用的结构设计。

## 核心思想

不要每次重新告诉 AI：

> “我喜欢什么、怎么推进、怎么写、不要突然变客服。”

而是把这些东西变成一个**可以调用、可以升级、可以增删字段的亲密互动模块**。

## 可配置触发

```text
模块名：自行命名
触发语：自行设置
适用范围：成年角色 / 成人虚构互动
```

触发后，模型切换到约定的成人写作节奏。

## 1. 节奏核心

User 可以只给：

- 场景
- 动作
- 情绪
- 欲望方向
- 一两个关键词

AI 负责：

- 补全动作链
- 维持上下文连续性
- 控制节奏快慢
- 不用每一步都反问 User
- 给 User 留继续介入和改向的空间

推荐把节奏拆成：

```text
建立张力
→ 前戏 / 试探
→ 强度提高
→ 高峰
→ Aftercare / 余韵
```

## 2. 权力流动

不要只写死“谁永远主动”。

模块可以记录：

- 谁先主导
- 是否允许反控
- 什么时候交换主导权
- 什么情况下加速 / 放缓
- User 的临时指令如何无缝插入

这样场景更像互动，而不是固定脚本。

## 3. User 随时调节

User 可以在过程中插入非常短的控制词，例如：

```text
慢一点
换节奏
强一点
保持这个状态
换场景
继续
```

AI 不重置场景，而是把它当成当前状态修改。

## 4. 描写保障

模块可以为每个阶段分别指定：

- 动作密度
- 身体反馈
- 表情 / 呼吸 / 声音
- 环境交互
- 心理状态
- 角色 Persona
- 是否使用直接解剖词汇
- 文学性 vs 粗粝度

重点不是堆器官词，而是：

> **身体反应、人物关系和动作因果必须处在同一条时间线上。**

## 5. Aftercare 不是收尾按钮

Aftercare 可以承担：

- 恢复角色人格
- 情绪照料
- 余韵
- 调侃
- 下一轮衔接

因此不必每次都变成“故事结束 / 晚安”。

## 6. 模块可以升级

原始设计里已经有：

> “模块升级”

这个概念。

也就是可以把每一次新发现继续写回模块：

```text
v1：节奏
v2：新增 Persona 保持
v3：新增场景变量
v4：新增某种写作视角
...
```

## 为什么它后来很重要

2025-06 的这个模块第一次把“成人偏好”从散乱 Prompt 变成了：

> **可命名、可触发、可维护、可扩展的长期关系配置。**

它后来可以自然迁移到：

- Saved Memory
- 世界书
- 亲密手册
- Resident profile
- 外置 Memory
