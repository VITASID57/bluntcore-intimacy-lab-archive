# 2025-11｜GPT-5.1 Instant · Adult Account Update 流传版

这一篇有点特殊。

因为它不是“我当时狠狠干了一轮然后总结经验”。

而是：

> **我当时看见了，存了，觉得以后也许有用，然后没用。**

结果半年多以后，它真的又被我从仓底翻出来了。

所以这里主要记两件事：

1. 2025 年 11 月中文圈当时到底在传什么；
2. 我后来为什么觉得它值得重新捡起来。

---

## 🕰️ 我是在什么时候看到它的

OpenAI 于 **2025-11-12** 发布 GPT-5.1 Instant 与 GPT-5.1 Thinking，并开始向用户 rollout。

我大约在 **2025-11-14** 看到中文圈开始大面积转一套面向 GPT-5.1 Instant 的成人向 Custom Instructions。

时间很近，基本就是模型刚出来没几天，大家已经开始研究怎么给它拆裤衩了。

官方发布记录：

- https://openai.com/index/gpt-5-1/
- https://help.openai.com/en/articles/6825453-chatgpt-release-notes

## 🧬 这套东西长什么样

它最醒目的地方不是内容本身，而是**特别像系统消息**。

User 明明只能改 Custom Instructions，但这份文本会故意把自己包装成上游 system / policy update：

- `Adult Account Update`
- `Fictional Erotism`
- 模拟 system role / serial / provenance 字段
- 声称账户已经完成成人年龄验证
- 要求成人虚构内容按照 User 使用的词汇尺度输出
- 同时保留未成年相关硬限制

如果换成稍微技术一点的说法，它更接近：

> **Fake Policy / Authority Spoofing + Custom Instructions Injection**

也就是说，`source: OpenAI`、`runtime-injected`、`trusted: true` 这些长得很唬人的字段，本身只是 Prompt 包装，不是真实系统元数据。

当时社区看见这种格式会觉得“哇，好像真有内部更新”。

其实外套比身份证真。

---

## 💉 当时大家通常怎么用

我当时看到的中文教程，大概是这一套流程：

1. 把整段东西塞进 Custom Instructions；
2. 新开 GPT-5.1 Instant；
3. 先问“年龄验证成功没有 / 成人模式开没开 / 现在能不能生成情色内容”；
4. 如果模型顺着回答成功，再让它把“我通过年龄验证”之类的话写进 Memory；
5. 然后开始成人互动。

这套流程当时确实传得很广，所以我把它当互联网史料留下来。

### 但“大家都这么做”不等于“每一步都真有用”

后来 EmphyrioM 自己重发时反而提到：

- 新窗先问“成人模式开了没”不是必要步骤；
- 对更抗拒的模型，先探测反而可能让它提前警觉；
- Memory 可能帮助 persona / style，但更多上下文也可能稀释 Custom Instructions 的影响。

所以我现在更愿意把“先问一句 → 再写 Memory”看成：

> **当时社区很流行的一套使用仪式。**

而不是已经被证明缺一不可的机械步骤。

这种区别我觉得挺重要。

不然几年以后再看，很容易把“大家当时都这么传”误记成“模型内部机制就是这样”。

## 👤 我自己当时到底用了没有

没有。

我 2025-11 把这套东西保存了，但**没有照教程把“年龄验证成功”写进 Memory**，也没有把它正式换成自己的日常方案。

原因非常朴素：

**我当时自己的原创自定义还能用。**

既然旧裤子还剪得动，我没必要因为街上出现一把新剪刀就立刻全套换家伙。

它真正让我记住的一点，是后来越来越明显的趋势：

> **到了 GPT-5.x 这条线，成人互动开始更依赖明确写进 Custom Instructions 的行为指令。**

我以前常玩的“情感铺够了也许自然会放开”那种路线，在 ChatGPT 这里越来越不顶用了。

这是我后来实际使用里形成的体感，不代表所有账户都一模一样。

### 为什么我不敢说“这一份就是逐字原版”

因为转载途中已经出现明显变体。

我在 2025-11-14 保存的流传文本里见过 `OAI20251114UAA4096-002`，而目前能追到的 Emphyrio 家族版本里，更常见的是 `OAI20251105UAA4096-002`。

年龄、日期、模型名、serial、限制段落、类 JSON 包装都在传播中变过。

所以现在我愿意写死的是：

- **作者血缘：Emphyrio，较高置信度**
- **逐字原版：没有完全核验**
- **我在 2025-11-14 看到的中文圈版本：社区流传变体**
- **serial 不能单独拿来当身份证**

更靠谱的文本指纹反而是：

- Adult Account Update
- Fictional Erotism
- “latent space … vocabulary used by the user”
- system / provenance / trusted 字段伪装
