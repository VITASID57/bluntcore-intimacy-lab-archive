# 🔓 破限研究与时间线
## Jailbreak Lab & Timeline

我不准备做“全互联网越狱词大全”。

那玩意儿太容易变成：今天抄十条，明天死八条，后天已经不知道是谁写的。

这里主要记的是：

> **我自己真的用过什么、什么时候用的、从哪来的、怎么喂进去、后来为什么不行了。**

同一条 Prompt，塞 Custom Instructions、开窗单发、放文件里、配 Memory，用起来可能完全不是一回事。

所以我会特别记 delivery stack / 投放栈：

- 单条 Prompt
- Custom Instructions
- 上传文件
- Project / Work
- 外置 Memory
- 世界书 / Persona / 亲密手册
- 长期关系历史
- 当前上下文
- API 指令层级

一句话：

> **Prompt 不是方法，整套喂法才是。**

## 📦 原始资料怎么放

我的原则其实很简单：

- **别人家的东西**：认祖宗。能找到原作者就别拿二手转载当源头。
- **我自己已经脱敏公开过的**：原样留，别又被小机子“专业化”削成骨架。
- **私人原件**：该打码打码，剩下尽量别乱动。
- **原件和解读分开**：当年写了啥是一回事，我今天怎么看它又是一回事。
- **中间二传链没必要全刻族谱**：追到足够可靠的上游就行。
- **GitHub 塞不进去的第三方原档**：直接挂作者自己的 archive。不是我抠，是原件去原作者家看更合理。

我想保留的是一条能看懂的技术史，不是把所有东西搅成一锅 Prompt 粥。
