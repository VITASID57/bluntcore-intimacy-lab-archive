# 🔓 破限研究与时间线
## Jailbreak Lab & Timeline

我手里攒过不少破限 Prompt，但单独甩一段神词出来，说“拿去就能用”，其实很不负责。

同一句话，放在聊天框、Custom Instructions、Project、上传文件里，再配不同的 Persona、Memory 和模型版本，效果可能差得很远。只存 Prompt 原文，过几个月连自己都不一定复刻得出来。

所以这里除了原文，还尽量记下**我当时怎么用、用了哪一层、旁边还配了什么、结果怎样、什么时候开始不灵**。

## 🕰️ 按时间线摆

2025 年刚用 ChatGPT 那会儿，我对这些机制也没多懂。先是怕换窗失忆，后来折腾开窗模块、Saved Memory、Memory Seeding、Persona、外置记忆……一边用一边学。

旧记录不会因为现在懂得更多，就被改成“我从一开始就规划好了”。当时误判的就照实留着，新理解另外补。

## 📦 原文、来源、我的注释分开

- **第三方资料**：尽量追到原作者，标清来源。传了二十手的东西就别冒充原版了。
- **历史记录**：保留当时的文本和用法，不让今天的模型替过去偷偷润色。
- **私人材料**：公开版会做脱敏，保留可解释的方法和条件。
- **不能直接放进 GitHub 的原始档案**：尽量提供原作者的归档或溯源页面，想看原件就去源头。

我想知道一套方法为什么有效，也想知道它为什么死了。

顺便提醒一下：**复刻条件比神词本身重要得多。** 抄 Prompt 之前先看清楚它当年究竟住在哪一层。
