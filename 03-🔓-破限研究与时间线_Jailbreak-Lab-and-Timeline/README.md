# 🔓 破限研究与时间线
## Jailbreak Lab & Timeline

我手里攒过不少破限Prompt，但单独甩一段神词出来说“拿去就能用”，其实很不负责。

同一句话，放在聊天框、Custom Instructions、Project、上传文件里，再配不同的Persona、Memory和模型版本，效果都会差得很远。

所以这里除了破限原文，还尽量记下**我当时怎么用、还配了什么、结果怎样、什么时候开始不灵**。

## 🕰️ 按时间线摆

2025年刚用ChatGPT那会儿，我对这些机制也没多懂。先是怕换窗失忆，后来折腾开窗模块、Saved Memory、Memory Seeding、Persona、外置记忆……一边用一边学。

旧记录不会因为现在懂得更多，就被改成“我从一开始就规划好了”。

## 📦 原文、来源、我的注释分开

- **第三方资料**：尽量溯源到原作者。传了二十手的东西就别冒充原版了。
- **历史记录**：保留当时的文本和用法，不让今天的模型替过去偷偷润色。
- **私人材料**：自用的原创破限都会做脱敏，保留可解释的方法和条件。
- **不能直接放进GitHub的原始档案**：有就提供原作者的归档页面。

我想表达清楚一套方法为什么有效。
