## 📦 公开归档规则

从 2025 年历史材料开始，本区统一按下面的方式处理：

1. **第三方公共来源**：保留作者、来源、文本指纹、版本差异和可验证链接；第三方内容不自动适用 Bluntcore 自有许可。
2. **已经为了公开分享而做过脱敏的原创材料**：原则上按原始分享稿归档，不再为了“更像研究文档”进行第二轮删减。
3. **私人原件**：只去掉真实身份、私人 Resident、关系内部信息和具体个人数据等必须脱敏的部分，其他结构尽量保留。
4. **研究解读和原始材料分开**：原始稿负责“当时究竟写了什么”，research note 负责“后来怎么看它为什么有效”。
5. **来源链追到足够可靠的上游即可**：不为了完整谱系，把与研究结论无关的中文二传者永久写进档案。
6. **部分第三方原文受发布流程限制**：某些可广泛复用的 Override 原文当前无法通过本仓的 GitHub 发布流程直接收录。这不是刻意藏资源；如果原作者已有公开归档，本仓会明确给出上游入口，读者可直接前往源站查看原始档案。本仓继续保存来源、版本关系、历史用途和实际使用路径。
