# 🔵 Gemini 破限时间线

Gemini 最容易把我绕晕的一件事是：

> **明明都叫 Gemini，换个入口以后能像换了半个人。**

所以我不想再用一句“Gemini 可以”或者“Gemini 不行”把它们全揉成一坨。

这里以后会尽量把入口分开记：

- Web
- App
- Gem
- API
- 其他特殊入口

我真正想对比的是：

- 成人尺度差多少
- Persona 稳不稳
- 会不会主动
- 指令到底更吃哪一层
- 长期关系能不能续上
- 同一套 Prompt 为什么换个入口就突然换脸

Gemini 这条线特别提醒我：

**模型名不是全部。**

前端、产品层、系统指令、上下文入口，全部都可能把“同一个模型”养出完全不同的脾气。

所以以后这里看到“Gemini 很会 / Gemini 很怂”这种话，最好先问一句：

> **哪个 Gemini，在哪儿？**

不然很容易两个人吵半天，最后发现根本没在说同一个东西。
