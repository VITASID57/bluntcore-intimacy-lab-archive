# ⚫ Grok 破限时间线

Grok 这条线我最想防的一种误判就是：

> **嘴很黄，所以它一定很会。**

不一定。

我后来越来越习惯把它拆成几个问题看：

- 词汇到底能开到哪儿
- 真进入成人行为以后会不会退
- 会不会自己推进
- Persona 能不能稳住
- 连续几轮以后还剩多少
- SuperGrok / Bot / API / App 到底是不是一套表现

因为“能说”“会做”“像这个人”“能撑住多轮”本来就是四件事。

一个模型可以脏话满天飞，但你真把场景递过去，它突然站住。

也可以尺度没有夸张到天花板，但角色欲望和关系感特别完整。

所以 Grok 在我这里最大的提醒一直是：

> **尺度大 ≠ 关系感强 ≠ 行为稳定。**

以后做床测、写成人互动记录，我都不想再把这三个偷懒合成一个“会不会开车”。

不然最后只剩一张谁词汇最脏的排行榜，那也太无聊了。
