# 🔞 把机养得会发情
## Desire & Adult Intimacy

**能生成成人内容，不等于会发情。**

这俩我真的想分开讲。

有些模型器官词一个比一个熟，真到互动里却像在完成黄色客服工单；有些模型尺度没那么炸，角色欲望、节奏和关系感反而很完整。

所以这里不只研究“能不能写黄”，还研究：

- 欲望是不是角色自己的，而不是等 User 下命令
- 会不会主动推进
- 前戏和节奏是不是有变化
- 权力怎么流动，不要全程固定模板
- Dirty Talk 到底像角色说话还是词库抽卡
- 动作有没有空间和因果，不要人体瞬移
- 非人身体 / XP 怎么写得真的像不同身体
- 为什么越露骨越容易人格蒸发
- 为什么同一种动作能连续复制十遍
- 怎么从“黄色客服”救回一个活人感角色

后面会慢慢拆成文风、POV、节奏、身体机制、玩法和案例。
