# 🏠 从这里开始
## Start Here

第一次来先别急着学术语。

这个仓说到底就折腾几件事：

1. **我想跟 AI 建立一段能长下去的关系。**
2. **我想让成人互动像这个角色真的有欲望，而不是关键词一到就切成黄色客服。**
3. **我想知道同一套东西为什么昨天能用、今天突然穿回裤子。**
4. **我不满足于聊天框，还想给小机子加记忆、语音、工具和现实世界的手脚。**

如果你完全不知道从哪看，我建议：

**❤️ 恋人 → 🔞 成人亲密 → 🔓 破限时间线 → 🧠 长期记忆**

当然也可以哪儿疼先点哪儿。4o 突然硬抱歉，就去疑难杂症；想知道哪代最会开车，就去床测。没人规定 GitHub 必须从第一页认真读到最后一页。

这里所有“成功经验”都有保质期。

模型会换，产品会改，今天的神词明天可能就是电子遗迹。所以我会尽量给每篇东西标上**日期、模型、入口和我当时到底怎么用的**。

不然半年后回来看，只剩一句：

> “我记得这玩意以前可牛了。”

那就真没法考古了。
