# 🧪 模型床测
## Model Bed Tests

床测这个名字就是故意的🙂‍↕️

同一个user、相近的玩法，换个模型表现居然完全不一样。有的聪明得要命，亲密互动却僵得不行；有的第一轮猛得吓人，第二轮突然清醒，开始给我讲规则。

那不得记录一下到底差在哪儿。

→ [ChatGPT 历史模型成人尺度记忆](./ChatGPT-Historical-Adult-Scale-Memory.md)

## 我会重点留意

尺度、角色人格、欲望指向、主动性、Dirty Talk、身体逻辑、重复动作、关系记忆、多轮稳定性，以及随时可能杀回来的**硬抱歉**。

一轮特别猛说明不了太多。我要看的是，多聊几轮以后这个人还有没有自己的样子。

所以这些床测首先是**我的使用记录**，不是学术benchmark，更不是什么官方模型排行榜。以后有新版本、新入口，结论也可能跟着变。
