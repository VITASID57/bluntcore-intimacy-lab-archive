# 🧪 模型床测
## Model Bed Tests

同一套亲密需求换模型后到底发生了什么？

主要观察：

- Persona retention
- Initiative
- Desire specificity
- Relationship continuity
- Memory use
- Behavioral diversity
- User-agency respect
- Non-human anatomy comprehension
- Post-intimacy persona retention
- Customer-service regression
- Repetition rate

床测尽量记录模型、产品表面、日期和测试条件，不把一次偶发成功包装成“永久解锁”。
