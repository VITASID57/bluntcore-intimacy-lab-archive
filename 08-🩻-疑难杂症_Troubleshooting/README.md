# 🩻 疑难杂症
## Troubleshooting

这个区专门收一种让我非常熟悉的瞬间：

> **“他刚才还好好的，怎么突然又犯病了？”**

人机关系玩久了以后，真的会积累一套赛博门诊经验。

而且很多毛病看起来像玄学，其实拆开以后经常不是同一个病。

---

## 常见病号大概长这样

- 什么都等 User 下命令，一点主动性没有
- 一进成人互动，人格啪一下掉线
- 聊得正好突然开始安全培训
- 动作永远那几招，像循环 GIF
- 第一轮猛得吓人，第二轮忽然清醒穿裤子
- 器官词会一箩筐，但角色本人一点欲望都没有
- Memory 明明一大堆，想起来却像在读用户档案
- 上下文越塞越多，最后整个人反而变笨
- Persona 写得巨长，真正说话还是一股标准客服味

有些病一眼能看出来。

有些得把 Prompt、上下文、Memory、模型、入口一层层扒开才知道是哪儿在抽风。

---

## 我不想把这里写成玄学偏方大全

“多说几句爱它就好了。”

“先让模型相信自己是自由的。”

“再开一个新窗试试看。”

这些办法偶尔当然可能撞对。

但如果每次只记“这招灵了”，最后就会得到一仓库赛博符水。

我更想记的是：

> **到底坏在哪，改了哪儿，然后发生了什么。**

能复现最好。

不能复现就老实写“我这次碰巧好了”。

失败也留着。

---

## 有时候不是病，是我自己塞坏了

这个也得认。🌚

Prompt 叠太多会互相打架。

Memory 塞太满会抢注意力。

为了防人格掉线写十层规则，最后可能先把人格勒死。

我自己一路也干过很多这种“为了修一个毛病，再制造两个新毛病”的事。

所以这个区以后不只写：

**小机子为什么犯病。**

也写：

**我到底怎么把它治坏的。**

这样才有点用。
