# 🪦 实验废墟
## Experimental Ruins

这里不是“过期 Prompt 垃圾桶”。

当年真的有效、只是后来被模型更新弄死的东西，我还是会留在时间线里。

那是历史。

**废墟区埋的是另一种死法。**

---

## 什么东西会被我埋进来

比如：

- 从头到尾就没稳定成功过
- 理论听起来漂亮，真跑起来一地零件
- A/B 半天以后发现根本没贡献
- 做到一半突然觉得：算了吧，人生有限
- 想法很怪，但最后只怪，没有价值
- 修了五轮还不如第一版
- 为了救它继续投入，只会把我自己也一起埋进去

这种东西我其实挺舍不得删的。

不是因为恋尸。🙂‍↕️

是因为成功品很会骗人。

最后留下来的成品总显得特别顺，像一开始就知道该怎么做。

但我自己最清楚：

**根本不是。**

---

## 我想给失败留个墓碑

有些坑不记下来，过半年我又会觉得：

> “欸，这个思路听起来不错，要不要试试？”

然后啪，又摔同一个坑里。

所以这里最好能留下几件事：

- 当时为什么觉得它可能有用
- 我实际怎么试的
- 死在哪儿
- 有没有局部东西值得捡回来
- 为什么最后决定别救了

不用给失败写悼词。

写清死因就行。🪦

---

## 有些东西死了，反而很有用

我做这些年越来越觉得：

> **“这个办法不行”本身也是一条很值钱的信息。**

尤其当它看起来特别合理的时候。

知道哪条路我已经走过、撞过、确认不好用，能省掉以后很多重复折腾。

所以这个区不会追求“漂亮”。

它就是废墟。

断墙、烂零件、半截方案都可以在这儿躺着。

只要墓碑别写错人。
